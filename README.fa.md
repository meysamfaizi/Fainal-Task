# راهنمای فارسی پروژه T04-Meysam-Faizi

این پروژه یک رابط فارسی و راست‌به‌چپ برای نمایش تراکنش‌هاست. با استفاده از HTML، CSS و جاوااسکریپت ساده ساخته شده و از Vite برای اجرای توسعه و ساخت نسخهٔ انتشار استفاده می‌کند.

## مشاهدهٔ سایت

[ورود به نسخهٔ آنلاین](https://meysamfaizi.github.io/T04-Meysam-Faizi/)

برای استفاده از نسخهٔ آنلاین، نیازی به نصب برنامه یا اجرای پروژه روی سیستم ندارید.

## نحوهٔ استفاده

1. سایت را باز کنید و روی دکمهٔ **بارگذاری تراکنش‌ها** بزنید.
2. فهرست تراکنش‌ها در یک پنجره نمایش داده می‌شود.
3. برای پیدا کردن یک تراکنش، تمام یا بخشی از شمارهٔ پیگیری را در کادر جست‌وجو وارد کنید.
4. با دکمه‌های **مبلغ** و **تاریخ**، ترتیب نمایش را تغییر دهید. کلیک دوباره، ترتیب صعودی و نزولی را جابه‌جا می‌کند.
5. برای بستن پنجره، روی دکمهٔ بستن بزنید.

مبالغ به تومان و تاریخ‌ها با قالب فارسی نمایش داده می‌شوند. داده‌ها از فایل `public/data/db.json` خوانده می‌شوند؛ این پروژه به حساب بانکی متصل نیست و امکان انتقال پول ندارد.

## امکانات

- رابط فارسی و راست‌به‌چپ با طراحی واکنش‌گرا
- نمایش نوع تراکنش، مبلغ، شمارهٔ پیگیری و تاریخ
- جست‌وجو بر اساس شمارهٔ پیگیری، با پشتیبانی از ارقام فارسی و انگلیسی
- مرتب‌سازی بر اساس مبلغ و تاریخ
- نمایش وضعیت بارگذاری، نبود نتیجه و خطای دریافت داده
- استفاده از فونت محلی وزیرمتن، بدون وابستگی به سرویس فونت خارجی
- پشتیبانی از اجرای محلی با Vite و Live Server
- انتشار خودکار روی GitHub Pages

## اجرای پروژه روی سیستم

### پیش‌نیازها

- Node.js نسخهٔ ۲۲٫۱۲ یا جدیدتر در شاخهٔ ۲۲، یا نسخهٔ ۲۴
- npm
- Git برای دریافت پروژه با دستورهای زیر؛ همچنین می‌توانید فایل ZIP مخزن را دریافت و استخراج کنید.

### دریافت و نصب

```bash
git clone https://github.com/meysamfaizi/T04-Meysam-Faizi.git
cd T04-Meysam-Faizi
npm ci
```

### اجرا با Vite

```bash
npm run dev
```

آدرسی را که در ترمینال نمایش داده می‌شود باز کنید و روی **بارگذاری تراکنش‌ها** بزنید.

### اجرا با Live Server

پوشهٔ اصلی پروژه را در VS Code باز کنید. اگر افزونهٔ Live Server را دارید، روی فایل `src/index.html` راست‌کلیک کنید و گزینهٔ **Open with Live Server** را بزنید.

در این حالت، داده‌ها از مسیر `public/data/db.json` خوانده می‌شوند. فایل HTML را از طریق سرور محلی باز کنید؛ باز کردن مستقیم آن با آدرس `file://` برای دریافت داده مناسب نیست.

## ساخت و پیش‌نمایش نسخهٔ انتشار

```bash
npm run build
npm run preview
```

نسخهٔ آمادهٔ انتشار در پوشهٔ `dist` ساخته می‌شود. آدرس نمایش‌داده‌شده در ترمینال را باز کنید؛ مسیر پایهٔ سایت `/T04-Meysam-Faizi/` است.

## ساختار پروژه

## انتشار در GitHub Pages

با ارسال تغییرات به شاخهٔ `main`، گردش‌کار GitHub Actions وابستگی‌ها را با `npm ci` نصب می‌کند، دستور `npm run build` را اجرا می‌کند و پوشهٔ `dist` را در GitHub Pages منتشر می‌کند.

تنظیم منبع انتشار Pages این مخزن روی **GitHub Actions** قرار دارد. فایل داده نیز هنگام ساخت به `dist/data/db.json` کپی می‌شود. در نسخهٔ آنلاین، مسیر CSS، فونت‌ها، جاوااسکریپت و داده با نام مخزن هماهنگ است.

برای مشاهدهٔ وضعیت انتشار، بخش **Actions** مخزن را باز کنید و گردش‌کار **Deploy to GitHub Pages** را بررسی کنید.

## رفع مشکلات رایج

- **نسخهٔ قبلی سایت نمایش داده می‌شود:** پس از موفق‌شدن انتشار، صفحه را با `Ctrl + F5` تازه‌سازی کنید.
- **تراکنش‌ها دریافت نمی‌شوند:** اتصال اینترنت یا فعال‌بودن سرور محلی را بررسی کنید، پنجره را ببندید و دوباره روی **بارگذاری تراکنش‌ها** بزنید.
- **پروژه با Live Server باز نمی‌شود:** پوشهٔ اصلی پروژه را باز کنید و Live Server را روی `src/index.html` اجرا کنید.
- **نسخهٔ محلی ساخته‌شده را می‌خواهید ببینید:** ابتدا `npm run build` و سپس `npm run preview` را اجرا کنید.
